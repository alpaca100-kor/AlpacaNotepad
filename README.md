# AlpacaNotepad

**알파카 메모장(Alpaca Notepad)**은 Windows 환경에서 업무 중 떠오른 아이디어, 전화 메모, 할 일, 임시 문구 등을 빠르게 기록하고 관리할 수 있도록 만든 가벼운 메모 프로그램입니다.

복잡한 문서 편집 기능보다는 **빠른 기록과 정리**에 초점을 맞추었으며, 현재는 일반적인 메모를 관리하는 **일반메모**와 날짜별 기록을 관리하는 **달력메모**를 함께 제공합니다.

알파카 메모장 소개 페이지:  
https://alpaca100-kor.github.io/AlpacaTools/tools/an.html

## 주요 기능

### 일반메모

일반메모에서는 여러 개의 메모를 목록으로 관리할 수 있습니다. 메모를 추가하거나 제거할 수 있으며, 위·아래 이동 버튼 또는 마우스 드래그 앤 드롭으로 메모 순서를 직접 변경할 수 있습니다.

메모는 제목과 내용으로 구성되며, 내용을 입력하는 즉시 저장됩니다. 프로그램을 종료했다가 다시 실행해도 기존 메모를 이어서 사용할 수 있습니다.

메모 내용은 클립보드로 복사할 수 있으며, 복사 완료 메시지를 화면에서 바로 확인할 수 있습니다. 메모 목록과 본문 편집 영역은 분리되어 있어 여러 메모를 빠르게 전환하면서 내용을 수정할 수 있습니다.

### 달력메모

달력메모는 특정 날짜에 내용을 기록하는 기능입니다. 날짜별로 메모를 저장하기 때문에 업무일지, 일정 메모, 작업 기록, 할 일 기록처럼 날짜와 함께 관리할 필요가 있는 내용을 작성하는 데 활용할 수 있습니다.

달력메모에는 다음과 같은 화면을 제공합니다.

- **월별보기**: 한 달의 달력을 보면서 날짜를 선택하고 해당 날짜의 메모를 작성
- **1년전체보기**: 1년 전체의 달력과 날짜별 메모 상태를 확인
- **목록보기**: 메모가 존재하는 날짜만 날짜순으로 모아서 확인

메모가 있는 날짜는 달력에서 시각적으로 구분되며, 오늘 날짜와 선택된 날짜도 별도로 표시됩니다. 이전 메모와 다음 메모가 있는 날짜로 바로 이동하는 기능도 제공하므로 날짜별 기록을 연속해서 확인하기 편리합니다.

대한민국 공휴일 정보도 함께 사용할 수 있습니다. 달력에서 공휴일 이름을 확인할 수 있으며, 목록보기에서는 **공휴일 표시** 옵션을 켜면 메모가 있는 날짜 옆에 공휴일 이름을 함께 표시할 수 있습니다.

달력메모는 별도의 데이터 파일로 저장되며, 일반메모와 마찬가지로 가져오기와 내보내기를 지원합니다.

### 날짜 및 시간 입력

**Alt + T** 단축키를 사용하면 현재 날짜와 시간을 커서가 위치한 입력창에 바로 삽입할 수 있습니다.

기본 입력 형식은 다음과 같습니다.

\`yyyy-mm-dd hh:mm:ss\`

일반메모의 제목·내용과 달력메모의 내용 입력창에서 사용할 수 있어 회의 기록이나 작업 시작·종료 시간 등을 메모할 때 편리합니다.

### 빠른 입력

**Alt + 1 ~ Alt + 0** 단축키를 이용하면 자주 사용하는 문구를 미리 등록해 두었다가 한 번에 입력할 수 있습니다.

빠른 입력 문구는 **설정 → 빠른 입력 설정...**에서 직접 지정할 수 있으며, 포커스가 있는 입력창에 해당 문구가 삽입됩니다.

반복적으로 작성하는 인사말, 업무 상태 문구, 자주 사용하는 표현 등을 등록해 두면 입력 시간을 줄일 수 있습니다.

### 클립보드 복사

일반메모와 달력메모의 내용을 클립보드로 복사할 수 있습니다.

복사 단축키는 기본적으로 **Ctrl + Shift + C**이며, 다른 프로그램의 단축키와 충돌하는 경우 다음 중 하나로 변경할 수 있습니다.

- Ctrl + Shift + C
- Ctrl + Alt + C
- Alt + Shift + C

단축키는 **설정 → 단축키 설정...**에서 변경할 수 있습니다.

### 메모 가져오기 및 내보내기

일반메모와 달력메모를 각각 별도로 가져오고 내보낼 수 있습니다.

일반메모는 JSON, TXT, Excel 형식으로 내보낼 수 있으며, 달력메모 역시 JSON, TXT, Excel 형식을 지원합니다. JSON 형식은 프로그램의 데이터 구조를 그대로 보존하기 때문에 다른 컴퓨터로 메모를 옮기거나 백업할 때 유용합니다.

Excel 내보내기 기능을 사용하려면 \`openpyxl\`이 설치되어 있어야 합니다.

가져오기를 실행하면 기존 데이터를 덮어쓸지 확인한 후 작업이 진행되며, 잘못된 JSON 형식이나 데이터 구조를 검사하여 오류를 안내합니다.

### 테마와 글꼴 설정

프로그램은 밝은 테마와 어두운 테마를 선택할 수 있으며, 설정한 테마는 다음 실행에도 유지됩니다.

메모 내용에 사용하는 글꼴과 크기도 설정 메뉴에서 변경할 수 있습니다. Windows 11 스타일의 UI 테마를 지원하며, 관련 라이브러리가 설치되어 있지 않은 경우 기본 Tkinter 테마로 동작하도록 구성되어 있습니다.

### 자동 저장과 데이터 안정성

메모를 입력할 때마다 데이터를 계속 저장하는 방식에서 발생할 수 있는 불필요한 디스크 쓰기를 줄이기 위해 최근 버전에서는 입력이 잠시 멈춘 뒤 저장하는 **디바운스 방식의 자동저장**을 적용했습니다.

일반메모와 달력메모는 각각 별도의 저장 대상으로 관리하며, 저장 과정에서 문제가 발생하면 사용자에게 저장 실패 사실을 안내하도록 구성되어 있습니다.

설정 파일과 메모 데이터는 프로그램이 설치·실행되는 폴더를 기준으로 관리하도록 되어 있어 실행 위치가 달라져도 사용자 데이터의 경로가 예상치 못하게 바뀌는 문제를 줄였습니다.

## 주요 단축키

| 기능 | 단축키 |
|---|---|
| 새 메모/달력메모 추가 | \`Ctrl + N\` |
| 내용 입력창으로 이동 | \`Ctrl + M\` |
| 주요 입력창으로 이동 | \`Ctrl + T\` |
| 목록으로 이동 | \`Ctrl + L\` |
| 선택 항목 삭제 | \`Ctrl + D\` |
| 이전 메모/날짜로 이동 | \`Page Up\` |
| 다음 메모/날짜로 이동 | \`Page Down\` |
| 현재 날짜·시간 입력 | \`Alt + T\` |
| 빠른 입력 | \`Alt + 1\` ~ \`Alt + 0\` |
| 일반메모 ↔ 달력메모 전환 | \`Ctrl + Tab\` / \`Ctrl + Shift + Tab\` |
| 달력 월별보기 | \`Alt + M\` |
| 달력 1년전체보기 | \`Alt + Y\` |
| 목록보기 공휴일 표시 전환 | \`Alt + H\` |
| 달력 이전/다음 달 이동 | \`Alt + ←\` / \`Alt + →\` |
| 클립보드 복사 | 설정에서 지정한 단축키 |

일부 단축키는 현재 활성화된 탭과 입력 영역에 따라 동작이 달라집니다. 예를 들어 일반메모의 \`Ctrl + N\`은 새 메모를 만들고, 달력메모의 \`Ctrl + N\`은 날짜를 지정하여 새 달력메모를 작성하는 창을 엽니다.

## 데이터 파일

프로그램은 실행 중 다음과 같은 파일을 사용합니다.

| 파일 | 용도 |
|---|---|
| \`memos.json\` | 일반메모 데이터 |
| \`memos_calendar.json\` | 달력메모 데이터 |
| \`quick_inputs.json\` | Alt+숫자 빠른 입력 문구 |
| \`settings.ini\` | 글꼴, 창 크기·위치, 단축키, 테마 등의 설정 |
| \`holidays.json\` | 대한민국 공휴일 참고 데이터 |
| \`an.ico\` | 프로그램 아이콘 |

메모 데이터는 프로그램이 종료되더라도 유지되므로, 중요한 자료는 JSON 파일을 별도로 백업해 두는 것을 권장합니다.

## 실행 환경

- 운영체제: **Windows**
- 개발 언어: **Python**
- GUI: **Tkinter / ttk**
- 기본 동작: Python 표준 라이브러리 기반
- Excel 내보내기: \`openpyxl\` 필요
- Windows 11 스타일 테마: \`sv_ttk\` 사용 가능

프로그램은 Python 소스코드 형태로도 실행할 수 있으며, 배포된 실행 파일은 GitHub Releases에서 확인할 수 있습니다.

## 최근 업데이트 내역

### 2026년 10월

최근 개발본에서는 프로그램 구조를 **일반메모/달력메모 탭 중심으로 재정리**하고, 각 탭이 자신의 기능과 단축키를 처리하는 구조로 개선했습니다. 이를 통해 향후 새로운 메모 탭이나 기능을 추가하더라도 기존 기능과의 충돌을 줄일 수 있도록 구성했습니다.

또한 달력메모에 **목록보기**를 추가하여 메모가 존재하는 날짜만 모아 볼 수 있도록 했으며, 목록에서 공휴일 이름을 함께 표시할 수 있는 옵션을 추가했습니다.

일반메모와 달력메모의 자동저장 처리도 개선했습니다. 연속적인 키 입력마다 파일을 저장하는 대신 입력이 잠시 멈춘 후 저장하도록 변경했으며, 저장 실패 시 사용자에게 명확하게 알리도록 보완했습니다.

### 2026년 9월

날짜별 기록을 관리할 수 있는 **달력메모 기능**이 추가되었습니다. 월별보기와 1년전체보기로 날짜를 탐색할 수 있으며, 날짜를 선택하여 메모를 작성하고 이전·다음 메모가 있는 날짜로 이동할 수 있도록 했습니다.

대한민국 공휴일 정보를 표시하는 기능과 달력메모 일괄 삭제 기능도 추가되었으며, 달력메모 역시 일반메모와 동일하게 가져오기 및 내보내기를 사용할 수 있도록 확장했습니다.

탭별 단축키, 달력 탐색 단축키, 메모 복사 기능 등을 정리하면서 키보드만으로 주요 기능을 사용할 수 있도록 개선했습니다.

### 2026년 8월

날짜와 시간을 커서 위치에 바로 삽입하는 **Alt + T 기능**과 자주 사용하는 문구를 등록하여 **Alt + 1 ~ Alt + 0으로 빠르게 입력하는 기능**이 추가되었습니다.

### 2025년 11월

클립보드 복사 동작을 개선하고, 클립보드 복사 단축키를 사용자가 변경할 수 있도록 했습니다.

마우스로 메모 목록을 드래그하여 메모 순서를 변경할 수 있도록 개선했으며, 프로그램 창의 크기와 실행 위치를 저장하고 복원하는 기능도 보완했습니다. 메모를 수정할 때 목록의 스크롤 위치가 불필요하게 이동하는 문제도 수정했습니다.

### 2025년 10월

메모 내용을 클립보드로 복사하는 기능과 상태 표시줄이 추가되었습니다. 상태 표시줄에는 메모 개수와 메모 내용의 커서 위치 및 글자 수를 확인할 수 있도록 구성했습니다.

## 개발 정보

알파카 메모장은 Python과 Tkinter를 기반으로 개발하고 있습니다.

현재 소스코드는 기능별로 메모 저장·설정 관리, 일반메모, 달력메모, 공통 메뉴 및 단축키 처리 영역을 분리하는 방향으로 계속 정리하고 있습니다.

코드 수정 및 개선 이력은 GitHub 저장소의 커밋 기록에서 확인할 수 있습니다.
